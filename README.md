##Dataset
The dataset used for this project is 'penguins.csv', which includes measurements for multiple penguin species

##Analysis Script
The analysis script 'penguins_analysis.R' performs two basic functions:
1. A table of summary statistics for the penguins, separated by species ('summary_stats.csv)
2. A scatter plot summary showing the relationship between flipper length and body mass ('flipper_vs_mass.png')

##How to Reproduce
1. Clone this repository
2. Open R
3. Run: r source ("penguin_analysis.R")
