### Author: Charlie Wilmot

##Dataset
The dataset used for this project is 'penguins.csv', which includes measurements for multiple penguin species

##Analysis Script
The analysis script 'penguins_analysis.R' performs some basic functions:
1. Loads the penguins dataset
2. Calculates a table of summary statistics for the penguins, separated by species ('summary_stats.csv)
2. Creates a scatter plot showing the relationship between flipper length and body mass ('flipper_vs_mass.png')

##How to Reproduce
1. Clone this repository
2. Open R or RStudio in the clones folder
3. Run the script ("penguin_analysis.R")
